# 跨境热销商品雷达：全量商品完整说明版

这是一个面向新手的免费、证据优先、严格分库的跨境商品研究系统。代码可放在公开 GitHub；商品结果在上传前使用 `age` 加密并用 Ed25519 签名，解密私钥只保存在本机 E 盘与 H 盘恢复包。

## 最重要的分库规则

- **可复用商品库**：身份、供应、物流、责任主体、风险、资料完整度、证据可信度和商业素材授权必须全部通过。
- **高热度不可复用研究库**：当前热度或历史峰值达到 60 分，但因授权、知识产权、召回、监管、供应或资料不足而不能安全商业复用。
- **普通热度不可复用商品**：不进入研究档案和 Excel。只在数据库待复核区观察最多 30 天；仍未升温则删除详情，只留匿名墓碑避免短期重复采集。
- **商品范围闸门**：正式两库只接收可上架的实体商品。人物、赛事、票务、应用、订阅和纯服务即使很热，也不能进入商品报表。
- 热度、浏览量、新闻、广告、评价和搜索量都是研究信号，绝不冒充真实销量或利润。

## 已接入的免费公开来源

- 11 个目标国家的 Google Trends 公开 RSS；
- GDELT 公开商品新闻线索（本机网络不可达时自动熔断，GitHub 云端仍会尝试）；
- 美国 CPSC、英国 OPSS、加拿大官方消费品召回 RSS、澳大利亚 ACCC 召回 RSS、新西兰官方召回站点地图；
- ECB 官方每日参考汇率；
- 经人工审核并加入白名单的公开 RSS、站点地图和 JSON-LD 商品页。

欧盟 Safety Gate、瑞士 RecallSwiss/BLV、TikTok Creative Center、Amazon、Temu、AliExpress、Etsy、WIPO、USPTO、EUIPO 只保留官方人工复核入口。系统不逆向接口，不绕过登录、验证码、付费墙、DRM 或反爬限制。

## 新手直接使用

1. 双击 `⑤系统体检.cmd`，确认本地项目健康。
2. 双击 `②立即采集并更新报表.cmd`，完成采集、分库、Excel 和 H 盘备份。
3. 双击 `③打开只读看板.cmd`，查看简单中文看板。
4. 首次连接 GitHub 时双击 `⑥连接GitHub云端采集.cmd`，本人在 GitHub 官方页面完成登录。
5. 之后可双击 `⑦同步GitHub并更新全部结果.cmd`；Hermes 的 30 分钟任务也会自动运行同一安全同步。

首次采集后两份正式 Excel 可能是空的。这表示当前没有商品达到严格门槛，不是程序失败。系统不会为了填满表格而降低标准。

## 输出位置

- `报表\可复用商品.xlsx`
- `报表\不可复用商品研究.xlsx`
- `可复用商品\`：逐商品完整 Markdown 档案
- `不可复用商品\`：只保存高热度不可复用研究档案
- `系统数据\跨境热销商品雷达.db`：唯一事实数据库
- `运行日志\`：健康快照与审计
- `H:\跨境热销商品`：版本化增量备份与密钥恢复包

## 安全与费用

- 付费 API、Pipiads、付费代理全部关闭；
- 单轮最多 250 个页面请求，单域名并发 1，间隔至少 2 秒，普通错误最多重试 2 次；
- 连续 3 轮失败的来源暂停 12 小时；
- GitHub Actions 每两小时运行一次，单次最长 12 分钟；定时任务可能因 GitHub 平台排队而略有延迟；
- 未知权利素材只保留公开链接和元数据，不下载、不去水印、不搬运、不商业复用；
- GitHub 只收到 `.age` 加密包、签名和无商品内容的清单，绝不上传数据库、明文结果或私钥。

## 开发与验收命令

- `npm run init`：初始化数据库、密钥与恢复包；
- `npm run collect`：从获准来源采集；
- `npm run export`：生成两份独立 Excel；
- `npm run backup`：创建 H 盘版本化增量备份；
- `npm run doctor`：系统体检；
- `npm run typecheck && npm test`：验证程序和严格分库规则。

详细步骤见 `新手操作指南.md`。两份最终规划文件位于项目根目录，并在 `H:\跨境热销商品\规划备份` 有同校验备份。
